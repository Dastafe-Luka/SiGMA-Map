# SiGMA World 2026 — DASTAFE სამიზნე რუკა

ეს საქაღალდე არის მზა ვებ-აპი GitHub Pages-ისთვის. iPhone-ზე Home Screen-იდან აპლიკაციასავით იხსნება,
ხოლო ერთხელ გახსნის შემდეგ ინტერნეტის გარეშეც მუშაობს.

## GitHub-ზე გაშვება
1. GitHub → **New repository** (მაგ. `sigma-map`). უფასო ანგარიშზე Pages მხოლოდ **Public** რეპოზიტორიაზე მუშაობს.
2. **Add file → Upload files** → ამ საქაღალდის ყველა ფაილი ატვირთე რეპოზიტორიის ფესვში
   (`index.html`, `sw.js`, `manifest.webmanifest`, `icon.svg` და ყველა `.png`) → **Commit changes**.
3. **Settings → Pages → Build and deployment**: Source = *Deploy from a branch*, Branch = `main`, ფოლდერი `/ (root)` → **Save**.
4. 1–2 წუთში ლინკი მზად იქნება: `https://<შენი-username>.github.io/sigma-map/`

## iPhone-ზე აიქონად დაყენება
1. ლინკი გახსენი **Safari**-ში (სხვა ბრაუზერში „Add to Home Screen“ შეიძლება არ იყოს).
2. **Share** (კვადრატი ისრით) → **Add to Home Screen** → **Add**.
3. ერთხელ გახსენი ინტერნეტით, რომ რუკა ტელეფონში შეინახოს. შემდეგ ექსპოზე ინტერნეტის გარეშეც გაიხსნება.

## განახლება
ახალ ვერსიაზე უბრალოდ შეცვალე `index.html` (და `sw.js`, თუ ისიც მოვიდა) იმავე რეპოზიტორიაში.
ტელეფონზე ახალი ვერსია მომდევნო გახსნისას გამოჩნდება.

## კონფიდენციალურობა
Public რეპოზიტორიის ფაილები და გვერდი ყველასთვის ხელმისაწვდომია, ვისაც ლინკი აქვს. გვერდი საძიებოებში
არ ინდექსირდება (`noindex`), მაგრამ თუ სიის საჯაროდ ყოფნა არ გინდა, რეპოზიტორიას ნეიტრალური სახელი დაარქვი.
